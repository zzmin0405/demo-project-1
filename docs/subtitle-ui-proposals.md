# 자막 UI 개선안

## 현재 상태 요약

현재 회의 화면의 자막은 영상 위 하단 중앙에 뜨는 오버레이 방식이다. 한 자막 카드 안에 사용자 이름, 번역 지연 시간, 번역 시작/완료 시간, 그리고 KO/EN/JA/ZH 4개 언어가 세로로 함께 표시된다.

발표용 기능 확인에는 충분하지만, 실제 서비스 화면으로 보면 정보가 한 카드에 많이 몰려 있고 영상 하단 컨트롤 영역과 가까워서 시선이 분산된다. 특히 4개 언어를 모두 켰을 때 카드 높이가 커지고, 긴 문장이 들어오면 영상 내용을 가릴 가능성이 있다.

## 목표

- 말하는 내용을 자연스럽게 따라가는 자막 경험 만들기
- 4개 언어를 보여줘도 화면이 복잡해 보이지 않게 정리
- 발표자 영상, 참가자 영상, 하단 컨트롤을 최대한 가리지 않기
- 번역 지연 시간 같은 개발/디버그 정보는 기본 화면에서 덜 드러나게 하기
- 모바일과 노트북 화면 모두에서 읽기 쉬운 구조 유지

## 안 1. 대표 언어 크게 + 나머지 언어 작게

가장 추천하는 방향이다. 사용자가 선택한 대표 언어 1개를 크게 보여주고, 나머지 언어는 아래에 작은 보조 줄로 표시한다.

예시 구조:

```text
한국어 번역 문장 크게 표시
EN English translation · JA Japanese translation · ZH Chinese translation
```

장점:

- 화면이 가장 깔끔하다.
- 실제 사용자는 보통 자기 언어 하나를 가장 중요하게 보므로 읽기 편하다.
- 4개 언어를 모두 보여주더라도 시각적 부담이 적다.
- 현재 코드 구조를 크게 바꾸지 않고 적용 가능하다.

단점:

- 네 언어를 완전히 동등하게 보여주고 싶은 데모에는 약간 약해 보일 수 있다.
- 대표 언어 선택 UI가 필요하다.

권장 사용:

서비스형 UI로 가장 적합하다. 발표 이후 완성도를 올릴 때 1순위로 추천한다.

## 안 2. 2열 그리드형 다국어 자막

4개 언어를 모두 같은 비중으로 보여주고 싶다면 자막 카드 안을 2열 그리드로 나누는 방식이 좋다.

예시 구조:

```text
KO 한국어 번역       EN English translation
JA Japanese text    ZH Chinese text
```

장점:

- 4개 언어 지원이 한눈에 보인다.
- 데모에서 "다국어 번역" 기능을 강조하기 좋다.
- 현재 세로 나열보다 카드 높이가 줄어든다.

단점:

- 모바일에서는 2열이 좁아질 수 있어 1열로 바꿔야 한다.
- 문장이 길면 각 칸 안에서 줄바꿈이 많아질 수 있다.

권장 사용:

기능 시연 중심 화면에 적합하다. 교수님/심사위원에게 다국어 지원을 명확히 보여주기 좋다.

## 안 3. 하단 한 줄 자막 + 사이드 번역 패널

영상 위에는 현재 선택한 언어 자막만 한 줄 또는 두 줄로 띄우고, 전체 4개 언어 번역은 오른쪽 사이드 패널에 기록처럼 쌓는 방식이다.

예시 구조:

```text
영상 하단: 지금 말한 문장 하나
오른쪽 패널: KO / EN / JA / ZH 번역 히스토리
```

장점:

- 영상 화면이 가장 덜 가려진다.
- 실제 화상회의 제품처럼 보인다.
- 이전 자막을 다시 확인하기 좋다.
- 회의록/요약 기능과 연결하기 쉽다.

단점:

- UI 변경 범위가 비교적 크다.
- 작은 화면에서는 사이드 패널을 접거나 탭으로 빼야 한다.

권장 사용:

최종 제품 느낌을 내고 싶을 때 좋다. 단기 수정용보다는 다음 단계 리팩터링에 적합하다.

## 안 4. 자막 카드 여러 개 대신 최신 자막 1개만 표시

현재는 최근 자막이 여러 개 남을 수 있다. 이를 최신 자막 1개만 크게 보여주고, 이전 자막은 빠르게 사라지게 하는 방식이다.

장점:

- 화면이 안정적이고 깔끔하다.
- 발표자 영상이 덜 가려진다.
- 자막이 밀려 보이는 느낌이 줄어든다.

단점:

- 사용자가 직전 문장을 놓치면 다시 보기 어렵다.
- 번역이 늦게 도착했을 때 이전 자막이 사라졌을 수 있다.

권장 사용:

발표 화면이나 집중 모드에 적합하다. 회의록 히스토리 패널과 함께 쓰면 단점이 줄어든다.

## 권장안

1차 개선은 **안 1: 대표 언어 크게 + 나머지 언어 작게**가 가장 좋다.

이유:

- 현재 구조에서 가장 적은 수정으로 화면 완성도가 올라간다.
- 발표 영상과 하단 컨트롤을 덜 가린다.
- 4개 언어 지원도 유지할 수 있다.
- 실제 사용자가 읽기 편한 구조다.

2차 개선으로는 **안 3: 하단 자막 + 사이드 번역 패널**을 추천한다. 이 방식은 서비스 완성도와 회의록 기능 확장까지 같이 가져갈 수 있다.

## 세부 UI 제안

- 자막 카드는 `max-w-3xl`보다 조금 좁히고, 긴 문장은 최대 2~3줄까지만 표시한다.
- 개발용 정보인 `latencyMs`, 번역 시작/완료 시간은 기본 화면에서 숨기고, 설정 또는 디버그 모드에서만 보이게 한다.
- 언어 라벨은 `KO`, `EN`, `JA`, `ZH` 텍스트만 크게 두기보다 작은 배지 형태로 정리한다.
- 카드 배경은 현재처럼 검정 반투명은 유지하되, 테두리와 그림자는 줄여 영상 위에서 덜 무겁게 보이게 한다.
- 자막이 새로 들어올 때 큰 애니메이션보다 부드러운 fade 정도만 사용한다.
- 모바일에서는 한 번에 대표 언어 1개만 표시하고, 다른 언어는 펼침 버튼이나 패널에서 확인하게 한다.

## 구현 우선순위

1. 대표 언어 상태값 추가
2. 자막 카드 레이아웃을 대표 언어 중심으로 변경
3. 나머지 언어를 보조 줄 또는 접힘 영역으로 이동
4. latency/time 표시를 디버그 전용으로 숨김
5. 모바일에서 카드 높이 제한과 줄 수 제한 적용
6. 이후 사이드 번역 히스토리 패널 검토
